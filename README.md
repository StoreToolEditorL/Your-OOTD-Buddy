# Your-OOTD-Buddy

`Your-OOTD-Buddy` 是一個個人化 OOTD 與穿搭決策技能，協助把抽象的風格感受轉換成可理解、可搜尋、可直接穿出門的搭配方案。

它會依照使用者的偏好、場合、台灣氣候、活動需求與預算，提供版型、色彩、材質、比例、單品搜尋詞及替代方案；需要視覺化時，會先取得同意，再以最低成本優先生成穿搭示意圖。技能也明確區分公開資料觀察、推測與個人建議，並遵守每個專案總共 300 點的生成成本上限。

## 內容

- `SKILL.md`：技能觸發條件與完整工作流程
- `references/user-preference-profile.md`：可由使用者確認後更新的偏好檔案

## 安裝

將 `your-ootd-buddy` 技能目錄加入你的 Manus skills 目錄，或下載根目錄的 `.skill` 套件後匯入即可。
