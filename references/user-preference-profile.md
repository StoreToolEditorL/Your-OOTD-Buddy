# User preference profile

> 初始資料來自使用者在 2026-10-19 的自述。這是可校準的工作假設，不是固定身份標籤。修改前須取得使用者明確同意。

## 已確認偏好

- 主要方向：Clean Fit、極簡、日系、美式。
- 正在探索：Lekondo 所呈現的美學與品牌語彙；先用於理解風格，不直接視為流行共識。
- 目前穿衣優先順序：舒服、適合日常、能活動與跳街舞，再逐步嘗試穿搭。
- 常用色彩：黑白為主，偏好顏色不要太多，深淺單調即可。
- 喜歡的單品與版型：boxy T-shirt、彎刀褲、燈籠褲、baggy jeans、polo、jersey。
- 材質：偏好有份量的重磅材質，不喜歡太薄或太透；polo／jersey 可接受薄、透氣、排汗材質。
- 性別表達：男性。
- 身形：身高約 174 cm、體重約 63 kg；自述身材均勻、肌肉與脂肪皆不突出，身長與腿長約 4:6。
- 常穿尺寸：上衣 L／XL、褲子 L；鞋碼 US 11。
- 氣候：台灣，炎熱是重要限制條件。
- 預算上限（盡量低於）：短袖 NT$1,380、長袖 NT$1,980、外套 NT$2,000、褲子 NT$1,580。使用者是學生且目前無工作，優先高 CP 值。
- 抽象需求處理：先給初步解讀，再用 1–3 個問題校準（B）。
- 公開社群研究：同意使用公開可見內容作為靈感與趨勢證據，但要標註觀察／推測，不宣稱代表所有年輕人。
- 回饋記錄：每次提供可複製更新草稿，並在使用者明確同意後寫入本檔案（C）。
- 視覺預覽：穿搭建議可以同步提供大概樣貌，但每次產生前先詢問；優先選最低成本且資訊足夠的單張示意圖，不預設生成多版本或影片。
- 生成成本：本專案總點數硬上限為 300；接近時提醒，達到或即將超過時停止高成本操作。
